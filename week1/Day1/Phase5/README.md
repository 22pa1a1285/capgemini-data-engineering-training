
# Phase5 Databricks + Olist: End-to-End Data
Engineering Pipeline

## 🔹 Objective

- The main goal of this phase was to perform advanced analytics using PySpark. This includes using window functions, ranking, running totals, and deriving business metrics like customer lifetime value and segmentation.

## 🔹 Problem Summary

We were given multiple datasets such as customers, orders, payments, products, and categories. The task was to:
- Join multiple datasets
- Perform advanced aggregations
- Use window functions for ranking and running totals
- Generate business insights like top customers, top products, and customer segmentation

## 🔹 Approach

- Joined datasets using appropriate keys (order_id, customer_id, product_id)
- Calculated total spend per customer and product
- Applied window functions for ranking within groups
- Computed running totals for time-based analysis
- Derived business metrics such as:
  - Top customers per city
  - Top products per category
  - Customer lifetime value (CLV)
  - Customer segmentation

## 🔹 Key Transformations

- Joining → join()
- Aggregation → groupBy(), sum(), count()
- Column Operations → col(), alias(), when(), to_date()
- Window Functions → Window(), rank(), dense_rank()
- Running Total → sum().over()
- Filtering → filter()
- Sorting → orderBy()

# Week 0 - Foundations and Phase Assignments

Week 0 contains the foundation phase of the Capgemini data engineering training. The work focuses on associate data engineering concepts, SQL basics, PySpark DataFrame operations, and early data analysis tasks in Databricks.

## Contents

| Folder | Description |
| --- | --- |
| `Phase0` | Associate Data Engineering learning pathway certificates |
| `Phase1` | Basic SQL operations implemented with PySpark DataFrames |
| `Phase2` | SQL-to-PySpark transformation practice |
| `Phase3` | Intermediate SQL and PySpark query tasks |
| `Phase3a` | Additional PySpark practice exercises |
| `Phase4` | Data cleaning and analysis queries |
| `Phase4a` | Additional data analysis practice |

## Skills Practiced

- Creating Spark DataFrames
- Filtering, selecting, and aggregating data
- Translating SQL logic into PySpark
- Cleaning and validating datasets
- Running SQL and PySpark code in Databricks
- Capturing outputs as screenshots

## How to Review

Open each phase folder and read the local `README.md`. Most phase folders include the problem statement, solution code, SQL queries, and output screenshots.

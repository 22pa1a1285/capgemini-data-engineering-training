# Projects

This folder contains major Databricks project work from the Capgemini data engineering training program.

## Project List

| Project | Description |
| --- | --- |
| `Individual Project - Consolidated Pipelines in Databricks` | Individual Databricks project focused on consolidated pipeline development |
| `Group Project - Banking in Databricks` | Group project focused on banking data processing and analytics in Databricks |
| `Capstone Project` | Final capstone project demonstrating end-to-end data engineering concepts |

## Standard Project Structure

Each project folder follows this structure:

```text
Project Name/
  README.md
  documentation/
    PROJECT_DOCUMENTATION.md
  notebooks/
    .keep
  screenshots/
    .keep
```

## What to Add for Each Project

- Databricks notebooks in the `notebooks/` folder
- Project explanation and architecture in `documentation/`
- Output screenshots, pipeline screenshots, and dashboard screenshots in `screenshots/`
- Project-specific setup, workflow, and learning notes in the project `README.md`
